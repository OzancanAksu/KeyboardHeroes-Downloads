# Keyboard Heroes Android v0.6.2 Beta — Match Results Hotfix

## Match completion
- A full-screen, touch-friendly Victory / Defeat / Draw result dialog now has Replay, Main Menu and Match Statistics controls.
- Replay begins a new bot match with the same settings; online Rematch returns the party to its shared lobby so the host can start the next game.
- Results include score, kills, deaths, assists, damage dealt, and elapsed match time.
- Hide obsolete HUD behind the result dialog; preserve safe-area and short-landscape support.
- Retains Deathmatch + Armağan, joystick, skill swipe-to-aim, potions and the KH app icon.

## Important
The Android APK is a WebView launcher. The game controls above are delivered by the official keyboardheroes.com.tr server, which must deploy the corresponding shared game-code fix.

## Installation
This is a **development-signed beta**, NOT a publisher-verified or Google Play-certified release. Requires Android 8.0+ and internet connectivity. Previous beta installations may require uninstall/reinstall if signing keys differ. Server-side account progress is retained.
