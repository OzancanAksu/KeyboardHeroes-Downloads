# Keyboard Heroes Android Phone & Tablet v0.5.1 — KH icon update

- Official gold KH shield and crossed swords logo now replaces the placeholder Android app icon.
- The launcher uses an Android adaptive icon with circular and standard masks; colors match the dark teal game theme.
- App icon is packaged inside the APK and works offline on the home screen, application list, and app settings.
- Existing mobile gameplay, inventory scroll fixes and skill swipe-to-aim features remain unchanged.
- This beta is debug signed. Android may require uninstalling the older beta when the ephemeral signing certificate differs; the game account remains on the server.
