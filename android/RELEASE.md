# Keyboard Heroes Android v0.6.0 Beta — Ölüm Maçı + Armağan

## New: Deathmatch + Gifts
- New **⚔️🎁 Ölüm Maçı + Armağan** mode, on the same mode-selector screen as Deathmatch and Armağan Labirenti.
- Eight-warrior free-for-all against seven bots, or 2–8 player online/LAN rooms when supported by the host.
- Large **Armağan Koridorları** arena with one random gift every 20 simulation seconds (maximum 3 at a time).
- Gift pickups: full health, +20% power/ability effect, +300 consumable armor, or +12% movement speed. Effects expire on death.
- Each enemy elimination awards exactly one FFA point, 7-second safe respawn, configurable kill goal (default 20), and 10-minute cap.
- Same authoritative gift and kill rules as Windows. Official gold KH launcher icon remains installed.
- Existing phone joystick, swipe-to-aim Q/W/E/R, inventory scrolling and potion controls retained.

## Installation
Development-signed APK v0.6.0; Android may require uninstalling v0.5.1 before installing if the temporary debug signing certificates differ. Account progress remains on the shared server. Requires Android 8.0+ and server connectivity.
