# Keyboard Heroes Android v0.6.7 Beta — Arcana Arsenal

- Q yetenek hasar açıklamalarında 4,5x çarpanın ikinci kez uygulanması düzeltildi. Gerçek temel değerler: **Üçlü Ok 113**, **Ağır Ok 171**, **Hilal Kesişi 130**, **Çember Biçiş 108**.
- Ekipman detayından **Geri** önce eşya listesine döner; eşya listesinde ikinci geri envanteri kapatır.
- Android sistem Geri tuşu da aynı iki aşamalı gezinmeyi izler.
- Envantere koyu mor, petrol yeşili, bakır/kehribar ve safir tonlarında yeni Arcana Arsenal teması, gelişmiş silah önizlemeleri ve kategorik ışıklar eklendi. Beyaz arka plan yok.
- Windows ile aynı çevrimiçi oyun sunucusunu kullanır; oyun içi yeni görseller HTTPS sunucusundan güncellenir.
- Native v0.6.7, **versionCode 14**; yükseltmede eski WebView cache temizlenir, sunucu hesabı ve kayıtlı build'ler korunur.
- APK geliştirme anahtarıyla imzalanır. Farklı debug sertifikalı eski beta yüklemesi Android tarafından reddedilirse kaldırıp yeniden yüklemek gerekebilir (cihazdaki yerel veriler silinir).
