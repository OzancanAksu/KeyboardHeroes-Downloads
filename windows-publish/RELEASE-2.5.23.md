# Keyboard Heroes Windows v2.5.23 — Illustrated Equipment

- Eight custom illustrated weapon icons and four matching garment illustrations applied to inventory cards and the live arena, sharing a single 640×480 WebP atlas.
- The same original fantasy artwork is used across desktop and Android. New art is cached as one 84,672-byte texture and not procedurally regenerated on every frame.
- Gameplay balance, multiplayer protocol 2.2.7, accounts, and stat values are unchanged.

## Build provenance
This is a compatibility build based on the **SHA-256-verified public v2.5.22 Windows ZIP and Setup.exe**, refreshed with the current game JavaScript and the exact live WebP atlas, the new MIME table entry, and a native version refresh. The private source repository is not copied to public CI. It is not a clean private source rebuild, and the EXE is not Authenticode-signed. Checks validate WebP bytes and SHA, local asset delivery, launcher assembly metadata, and the installer’s embedded ZIP.
